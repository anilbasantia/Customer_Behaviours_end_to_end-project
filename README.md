# 🛍️ Customer Shopping Behavior Analysis
### End-to-End Data Analytics Project | PostgreSQL • Python • Power BI

## 📌 Project Overview

This project analyzes customer shopping behavior to uncover insights into purchasing patterns, customer segmentation, product ratings, discount usage, subscription status, shipping preferences, and revenue contribution across age groups.

The project follows an end-to-end data analytics workflow, using **Python for data cleaning and exploratory data analysis (EDA), PostgreSQL for business analysis, and Power BI for interactive dashboard reporting.**

The goal is to transform raw customer shopping data into meaningful insights that can support data-driven business decisions.

## 🎯 Business Objectives

- Analyze revenue contribution by customer gender and age group.
- Understand the relationship between discounts and customer spending.
- Identify top-rated products and products with high discount usage.
- Compare purchasing behavior between subscribers and non-subscribers.
- Evaluate average purchase amounts across shipping methods.
- Segment customers into new, returning, and loyal groups.
- Identify top-performing products within each category.
- Analyze repeat purchasing behavior and subscription preferences.

## 🔄 Project Workflow

1. **Data Loading:** Imported the customer shopping dataset into Python using Pandas.
2. **Data Exploration:** Examined the dataset structure, descriptive statistics, and missing values.
3. **Data Cleaning:** Handled missing review ratings using category-level median imputation and standardized column names.
4. **Feature Engineering:** Created age groups and converted purchase-frequency categories into day-based values.
5. **Database Integration:** Loaded the processed dataset into PostgreSQL using SQLAlchemy.
6. **SQL Analysis:** Developed business queries using aggregations, conditional logic, subqueries, CTEs, and window functions.
7. **Dashboard Development:** Used Power BI to build an interactive dashboard for exploring customer behavior and business performance.

## 📊 Key Business Questions & SQL Analysis

The PostgreSQL analysis addresses the following ten business questions:

1. **Revenue by Gender:** What is the total purchase revenue generated by male and female customers?
2. **Discounts and Spending:** Which customers used discounts while spending at or above the overall average purchase amount?
3. **Top-Rated Products:** Which five products have the highest average review ratings?
4. **Shipping Comparison:** How does the average purchase amount compare between Standard and Express shipping?
5. **Subscription Analysis:** How do customer count, average spending, and total spending differ between subscribers and non-subscribers?
6. **Discount Rate by Product:** Which five products have the highest percentage of purchases using discounts?
7. **Customer Segmentation:** How many customers fall into the New, Returning, and Loyal segments based on previous purchase counts?
8. **Top Products by Category:** What are the top three products in each category based on customer purchase counts?
9. **Repeat Buyers and Subscriptions:** How many customers with more than five previous purchases are subscribers versus non-subscribers?
10. **Revenue by Age Group:** Which age groups contribute the most purchase revenue?

## 🐍 Python: Data Cleaning & EDA

The Jupyter Notebook contains the following analytical steps:

- Loaded and inspected the customer shopping dataset.
- Examined data types, descriptive statistics, and missing values.
- Imputed missing review ratings using category-level medians.
- Standardized column names for easier analysis.
- Renamed the purchase amount column.
- Created age groups using quantile-based binning with `pd.qcut()`.
- Converted purchase-frequency categories into approximate day intervals.
- Checked the relationship between discount application and promotional code usage.
- Removed the redundant promotional-code column.
- Connected Python to PostgreSQL and loaded the processed data into the `customers` table.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/anilbasantia/customer-shopping-behavior-analysis.git
cd customer-shopping-behavior-analysis
```

### 2. Install Python dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```

### 3. Run the Python notebook

Open Jupyter Notebook:

```bash
jupyter notebook
```

Open `analysis.ipynb`, update the dataset path, and execute the cells in order.

### 4. Configure PostgreSQL

- Install and start PostgreSQL.
- Create a database named `Customer_Behaviours`.
- Update the connection settings in the notebook.
- Execute the data-loading section to create or replace the `customers` table.

**Security:** Do not publish your database password in the notebook. Use environment variables or another secure credential-management method before uploading the project to GitHub.

### 5. Execute SQL analysis

Open `sql_analysis.sql` in pgAdmin 4 or another PostgreSQL client, connect to the database, and execute the queries after the `customers` table has been created.

### 6. Open the Power BI dashboard

Open `customer_behaviours_dashboard.pbix` in Power BI Desktop. If prompted, configure the data source and refresh the data as required.
